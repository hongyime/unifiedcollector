04 / UNDERSTAND

Analysis

The downstream Analyzer turns supported evidence into:

  • Identity leads
  • Relationships
  • Activity timelines

A discovered account is a lead, not automatic proof that two identities are the same.

Enrichment does not hold up collection. Stored source evidence is available to the Analyzer directly. Follow-up checks add findings asynchronously; supported findings can then contribute to analysis. Not every tool output is automatically linked to an identity.

Browser collection support

Shared infrastructure for sources that need a browser session.

Managed browser→Page capture→Collection gateway

Capabilities first. Delivery methods second.

A platform may need more than one collection method. That does not make it two business capabilities.

The Lemon8 question

One Lemon8 capability, two complementary methods

The backend handles routine profile, feed and discovery work. Optional browser capture can contribute visible media and discover creators; those creators can be queued for backend follow-up.

Both methods produce Lemon8 evidence. Stable identifiers and media deduplication reduce repeated records. Some requests can still overlap—the overview should not pretend there are two independent Lemon8 products, or promise zero duplicate work.

The naming question

“Browser collection gateway” says what it does

The gateway receives captured content from multiple platforms, stores records and offers collection targets. It is shared browser infrastructure, not an Instagram-only collector.

The browser control channel lets maintenance inspect and repair Chrome. The extension extracts page content; the gateway receives that content. Control and capture are different responsibilities.

Show what happens automatically today
  • The scheduled recon seeder periodically selects observed usernames. Domain/URL seeding exists but is not enabled in that default scheduled path.
  • Recon workers select a lookup engine for each target and store observations. Exposure searches are a related enrichment capability with a separate input path.
  • The Analyzer’s recon bridge turns supported username observations into weak identity signals where an existing platform link can be resolved.
  • GHunt email observations are stored, but that username-only bridge does not automatically attach them to identities.
  • Analyzer WMN fan-out starts from already known identity handles. It is an optional downstream check, not an additional source collector.

Operator controls: RECON_USERNAME_MODULES and RECON_USERNAME_ENGINE select Collector username behavior; WMN_FANOUT_ENABLED controls Analyzer WMN. GHunt requires a resolvable GHUNT_CREDS file and executable, plus an email target routed to that engine. Existing queued selections are not rewritten by changing defaults.

What “working” actually means

A running process, a responding browser and fresh evidence answer different questions.

Collection is producing

Useful recent content proves capture. Heartbeats prove the extension is alive; they do not prove new posts or media were stored. Unavailable checks must stay unknown.

Recovery is available

Browser maintenance belongs on the Windows host. Restarting a collector container cannot, by itself, restart Chrome or repair a broken browser session.

Evidence is recoverable

A completed backup and a successful restore drill are stronger proof than a partial file or a readable archive index. Schedule only after accepting the workload impact.
