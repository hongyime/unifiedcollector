  - [x] 3.3 Create _make_request_with_retry() method
    - Add new method to `Lemon8Scraper` class with signature:
      - `def _make_request_with_retry(self, url: str, max_retries: int = 3, account: str = 'default', referer: Optional[str] = None, timeout: int = 30) -> requests.Response:`
    - Implement retry loop:
      - `for attempt in range(max_retries):`
      - Before each attempt: `self.rate_limiter.wait(account)`
      - Apply rotating headers: `self._apply_rotating_headers(endpoint_kind='page', referer=referer)`
      - Make request: `response = self.session.get(url, timeout=timeout)`
      - On success (200-299): `self.rate_limiter.record_success(account)` and `return response`
      - On 429: `self.rate_limiter.record_rate_limit(account)`, log warning, continue to next retry
      - On 403: `self.rate_limiter.record_error(account)`, log warning, continue to next retry
      - On other 4xx/5xx: raise immediately (don't retry client errors like 404)
    - After max retries exhausted: raise the last exception with context
    - Add exponential backoff logging: show attempt number and delay used
    - _Bug_Condition: isBugCondition(request) where request has no retry logic for 403/429_
    - _Expected_Behavior: Requests retry up to max_retries times with exponential backoff and jitter_
    - _Preservation: No existing methods are modified, only new method added_
    - _Requirements: 2.2, 2.4, 2.7_
