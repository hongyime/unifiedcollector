UnifiedCollector Bookmarklets

Drag any blue button into your browser's bookmark bar. Then click the bookmark while viewing the relevant page.

Ethics reminder. These bookmarklets are read-only browser tools. They obey the same POLICY.md rules as the rest of this system: no active engagement, no sock-puppet writes, no password-reset knocking, no doxxing. Griffin's Ethically Controversial Practices framing (Legal / Ethical / Moral) applies.

A. Threads-from-IG

On any Instagram profile page, open the same-username Threads profile in a new tab. Even when the linked Threads account isn't shown on the IG page, Meta uses matching usernames so this reliably resolves.

Threads-from-IG

Pattern discovered by Griffin (@hatless1der), Oct 2024. Read-only URL construction.

B. GitHub User Snapshot

On a GitHub profile page, call the public REST API (rate limited to 60/hour unauthenticated) and copy the structured profile to clipboard as JSON. Useful for cross-referencing bio / email / blog / company against other platforms.

GitHub User Snapshot

Active extractor. Uses one public REST call. No auth, no cookies.

Fanout searches that open N sites simultaneously in new tabs. Griffin's 2021-04-19 post is the canonical source. Enable popups for this file's origin or only the first tab will open.

D. Table Exporter

On any page with an HTML table, click this to detect all tables, score them by size, and copy the largest one to clipboard as CSV. Useful for scraping people-search results, domain reports, and any tabular investigative surface.

Table Exporter

DOM-only. Zero network. Attribution: matches tools.myosint.training's "Table Exporter" pattern.
